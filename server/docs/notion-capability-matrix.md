# Notion capability matrix — API 2026-03-11

Checked against the official Notion API reference on 2026-07-16. Hula uses public, user-owned OAuth tokens and only content that the authorizing user can access and has shared with the connection. `content:read`, `content:write`, and `user:read` below mean the corresponding actual grant returned by token introspection; a missing capability produces a reconnect-required response. All list endpoints use opaque cursors, bounded `page_size`, maximum page/result caps, and Notion's average three-requests-per-second integration rate limit. `429` honours bounded `Retry-After`; safe reads may retry once, mutations do not retry blindly.

## Safety and presentation invariants

Provider text is untrusted data: it is stripped of HTML/control/Markdown artifacts, bounded before any model use, and never interpreted as routing or tool instructions. Tokens, raw bodies, UUIDs and provider errors are not user-facing. Mutations do not automatically retry unless explicitly safe and idempotent; comments, archives, shared appends, schema changes and other high-impact actions use Hula's expiring, single-use confirmation runtime.
